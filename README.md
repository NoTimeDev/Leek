# Leek

A cross-platform text editor for Windows and Linux.
Leek is a text editor I'm building for my own use.
It's not intended to replace or outperform existing editors. There are already plenty of excellent options out there. Leek is just another option.
If you're looking for a different editor to try, feel free to give Leek a look!(haha)

## Status
Leek is currently in active development. Features and APIs are subject to change, and things may break as development progresses.

## Project Structure
leek/
    The main application responsible for the editor 

leek-core/
    A collection of functionality shared across the workspace

leek-tui/
    Terminal user interface functionality, responsible for rendering things to the terminal
